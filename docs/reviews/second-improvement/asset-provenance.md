Exports `createCleanupScene({THREE, explorerTemplate})` returning `{scene, root, update, cameraPose, dispose}`. `scene` is a separate lit THREE.Scene; `root` is origin-local. ## Integration contract

`update(state, dt, {reducedMotion})` reads `state.cleanup.attempt` and permanent `state.cleanup.completed`; it does not write domain state. The final `CLEANUP_SITES` catalogue supplies all six IDs and coordinates. Presentation supports home-reef only. Surface Y=0, seabed approximately Y=-9; domain bounds remain X±8 and Y[-8,0].

`cameraPose(aspect, variant='side')` returns `{position:[x,y,z], target:[x,y,z]}`. `'oblique'` supplies the comparison angle. Poses assume approximately 42° vertical FOV (PM camera's 43° adds a small margin). Root must not be offset separately from these poses.

Permanent completion alone fades affected water and revives the larger fish school. Collection uses the existing trash mesh in a bounded flight into the bag; retry restores meshes, scale, pose, bag count and flight state. Bag lag is visual only. Reduced motion holds decorative motion and removes collection arc/spin, retaining a short direct transfer for causality.

`dispose()` is idempotent and releases owned geometries, materials and textures, then clears its scene. It does not dispose the shared renderer or template. PM's current integration calls this method before releasing the overworld. Alternatively, a recursive external release of this separate scene can own cleanup; avoid double-release. No per-frame geometry/material creation, no particle spawning, and six reusable trash flights.

## Technical checks and limits

- JavaScript syntax checked; actual Chrome/Vite rendering succeeded with real GLB and both camera variants.
- Fifty staged partial-collection/failure/retry cycles restored all six trash silhouettes, each visible with scale 1. Initial GPU geometry count changed by one as an additional bag-content mesh first became visible; this is lazy upload, not persistent allocation growth.
- After warming full restoration and retry, twenty further complete/failed/active presentation cycles held renderer geometry count at **151 → 151**, textures **0 → 0**. Calling `dispose()` twice left renderer counts **0 geometries, 0 textures**.
- A representative affected reef frame reported **113 draw calls, 67,038 triangles, 12 line segments**. This is an isolated art-stage sample, not a performance benchmark or integrated total. Additional fish on restoration increase draws.
- No `scene.js`, `main.js`, domain, or UI files were edited by this specialist. No advanced gear, fins, scuba, sharks, rewards or persistence logic added.
- Earned collect/surface/fail/retry/complete/save sequences, integrated square UI, frame timing, input feel, and independent quality assessment remain the integration review's responsibility.
