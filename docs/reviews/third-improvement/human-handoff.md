# Tidekin 0.4.0-beta.1 — hands-on comparison

Open **http://127.0.0.1:5181/** in your usual browser/profile. Reload an already-open tab to load this build. The saved voyage stays at the same origin/key. Existing restored reefs remain restored, with no retroactive rewards; to experience the new earned opening, start a new voyage only if you intend to replace that browser's save. A separate browser/profile gives a fresh voyage without replacing it.

## First outing

Follow the single opening note, or skip it and revisit Pause → How to play. H takes the helm; W/S moves along the bow, A/D steers. E gathers reachable floating material. Restore the two orange-flagged patches by entering Dive, swimming close to each target, and holding it. Swim to the bright surface for air. Failure clears this attempt and offers immediate retry. Return after completion to keep the once-only wood/scrap reward.

The initial timber and both restorations fund the wheel. Open Workshop (B) and build it aboard the raft wherever you are. Try the sheltered current before/after building. Map (M) → Track Mangrove shows a persistent bow-relative arrow. Sail there, then track Home through the same map and return. Continue preserves earned progress.

## Compare without spending your voyage

Open **Compare**, or underwater use **Escape → Compare prototypes**. Start a clearly labelled disposable reef trial; Return to my voyage restores the held voyage. Trial resets grant nothing and suppress saves. Reload returns to the last saved voyage.

| Choice | What to try |
|---|---|
| Directional / pointer swimming | WASD swimming with held target actions; or hold empty water to swim and begin a separate hold on an object to work. Release before changing intent. |
| Pull / clean | Pull holds one reachable object until release and stowing. Clean holds and sweeps all three dirty bands. A stationary center hold intentionally leaves the side bands. |
| Original / quicker pace | Same air and targets; only swimming response differs. |
| Following / first-person helm | Try turns, approaching material and a pickup from both views. Take the helm for sailing. |

All four swim/action combinations remain available. A variant change clears unfinished action coverage, keeps already completed objects in that attempt, and grants no reward. Hold E or the action button is a fallback; its cleaning action sweeps automatically. Normal reef breathing preserves work; the optional Pearl survey still requires one continuous breath.

Try the combinations in whichever order feels useful. The provisional default is directional swimming, pull, quicker pace and following camera. No preference has been established by the agents.
