# Third-improvement editable art and provenance

No downloaded third-party art or new generated raster image was introduced in this iteration. The original title illustration and reference image remain the visual anchors, and existing workshop/island/landmark Blender/GLB assets remain in place. Historical provenance is retained in the second-improvement asset record.

| Source | Ownership and change |
|---|---|
| `assets/ui/compass-rose.svg`, `assets/ui/chart-waves.svg` | Original small editable vectors produced by UI specialist Raman. Used by paper instruments/chart; no external font service. |
| `src/style.css`, `index.html` | Editable interface composition, responsive layouts, contrast/focus/reduced-motion treatments and optional grouped tools. |
| `assets/cleanup/reef-art.js` | Original procedural Three.js geometry by underwater specialist Ptolemy: limestone ledges, snagged rubbish, dirty bands, net/tether/contents, timber/pearl/survey identities. Revised after independent review. |
| `src/cleanup-scene.js` | Editable clone articulation and animation, site-resource ownership/disposal, particles/vegetation/local restoration and read-only screen projections. Existing Explorer model reused. |
| `src/scene.js` | Original procedural helm/bow/storage proxy, pooled material transfer, buoy pollution, labels and instanced inward foam. Existing merged shell visibility changes only during helm rendering. |
| `src/main.js` | Locally synthesized filtered underwater noise and short oscillator feedback; no fetched audio files. Sound remains optional. |

Staged renders in `captures/third-improvement/art-refinement/` were source-preview geometry checks and are explicitly not earned gameplay. Actual build captures, motion and comparison dispositions live under `captures/third-improvement/design-review/` and `qa/`. Existing title/menu pixels are preserved; surrounding styling changed. New procedural sources are the editable artifact, not a claimed new Blender export.

Final manifest hashes identify shipped sources and assets. See sailing-art.md, underwater-art.md and ui-art-direction.md for production intent; independent design-review.md is the acceptance record.

Release audit compared the existing second-improvement manifest: `public/assets/menu-art.png`, `workshop.glb`, `island.glb` and `landmarks.glb` all retain exactly the prior SHA-256 hashes. The changed reef-art source is intentionally new.
