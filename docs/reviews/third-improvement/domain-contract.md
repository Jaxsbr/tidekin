## Cleaning coverage contract (implemented)

`attempt.cleaning` maps target ID to `[left, middle, right]` fractions 0..1. Each target has a horizontal 0.8m cleaning strip centered on `{x,y}`; three equal segments. `steerGame` also accepts `aim:{x,y}` in dive-world coordinates. UI latches `targetId` at pointer-down, updates aim while held, and never silently switches the target. Aim must be within target x +/-0.4 and y +/-0.45; swimmer must independently be within normal 1.25m reach. Each segment needs .8/3 seconds of active coverage; holding one location never completes untouched segments. `actionProgress` is mean coverage. Renderer can remove pollution per segment.

For E/accessibility with **no aim property**, clean action automatically sweeps the first unfinished segment. Pointer UI must supply aim (including invalid/out-of-strip coordinates) so it cannot accidentally invoke that fallback. Pull retains uninterrupted hold semantics. Cleaning coverage persists on release, reselect and movement, but clears on failure, retry, exit/reload, or comparison variant change; completed targets remain. Practice coverage is transient.

## P2 raft-footprint refinement

A 4.5m centre circle does not cover the corners of the baseline 7x9m hull: a corner lies approximately 5.70m from the raft centre. Aboard salvage reach is now the union of that existing circle and the heading-oriented hull rectangle, half-width 3.5m on local X and half-length 4.5m on local Z. This geometry-derived change admits actual hull overlap without increasing reach to a 5.70m circle. Exact boundaries are inclusive; a 1e-12 roundoff tolerance handles rotated endpoints, while points 1e-6 outside both shapes remain excluded.

`game.js` exports `RAFT_HALF_WIDTH`, `RAFT_HALF_LENGTH` and pure `salvageReach(state, position)`. World offsets rotate into raft-local coordinates using `localX = dx*cos(heading) - dz*sin(heading)` and `localZ = dx*sin(heading) + dz*cos(heading)`. Historical world swimmers retain their existing circle-only reach.

`getContext().nodes[].inReach`, `nearby`, `gatherTarget`, gather actions, `getDiveSite` exported from **game.js**, public Dive and explicit public `enter-cleanup` salvage entries use this reach. `distance` remains centre distance for display and stable nearest-first sorting. UI permission labels should use domain `available`/`reason`, not reconstruct permission from that distance. Tide, underwater-only access, upgrade gates, survey buoy radius and starter cleanup entry radii remain unchanged.

The facade handles hull adjudication for side-view salvage entry using a temporary entry view positioned at the already-reachable node, then copies the successful helm transition back. The authoritative raft position never moves; cleanup/stat records use the existing dispatcher transition and capability checks. No cleanup module edit was needed. Direct low-level cleanup APIs retain their circular entry contract; public consumers should use the game facade.
