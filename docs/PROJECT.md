# Tidekin

A little workshop. An endless ocean.

Tidekin is a local single-player ocean exploration prototype: sail a handmade raft, restore selected reefs, gather useful supplies, and grow a floating home. Human feedback favors understandable progress and charming, coherent presentation. The supplied reference is an art target, not a claim of achieved game quality.

[Current contract](governance/current-contract.md) is the baseline behavior and ownership authority. [Governance index](governance/README.md) routes asset, approval, retention and historical-cleanup work. Current implementation/review evidence belongs to the coordinator and current art/performance owners; older numbered improvement plans are historical.

Delivery requires a working earned progression arc and validated persistence, intact user references and editable sources, reviewed domain/rendering ownership, meaningful tests, identified actual-input integration evidence, and hardware measurements bound to their exact build. Agent judgments remain distinct from human approval and enjoyment. Numerical targets and controls from a retired iteration are not implicitly new user requirements.

Preserve the existing browser-local save origin and key. Production cleanup changes asset packaging only after actual consumer tracing; a frozen measured distribution remains intact until its owner finishes. Consult the current architecture document for the integrated resource-disposal interface rather than copying historical cleanup traversals.
