For island generation, reference matching or biome curation, follow [docs/studies/biome-generation-procedure.md](docs/studies/biome-generation-procedure.md). The maintained tool is `tools/island-lab/`; historical source/captures are immutable evidence under `docs/decisions/evidence/`.

Jaco accepted the lab as a decent starting point and requested merge preparation. That scope does not approve exact production visuals or runtime island integration. Preserve the no-arch lagoon, low-to-high shoreline hierarchy and all-direction approach requirements. Agent rubric scores do not grant human approval.

Keep tool imports, study assets and browser storage separate from production gameplay. Record recipe/source identities, fixed-view captures, per-aspect scores and limitations before changing a reviewed version. Run `npm test`, `npm run islands:check`, the browser checks and the production build for tool changes. Preserve unrelated work and existing voyage saves. The integration document is a proposal for discussion, not authority to replace the game world.
